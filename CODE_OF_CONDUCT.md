# Code of Conduct

Praxis uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project respectful and welcoming for everyone.

## Expected Behavior

- Be kind, clear, and constructive.
- Assume good intent, but accept feedback when impact differs from intent.
- Keep technical disagreement focused on the work.
- Help new contributors understand the project without gatekeeping.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Demeaning language or exclusionary behavior.
- Sharing private information without permission.
- Repeated disruption of project spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that are not aligned with this Code of Conduct.

This short form is adapted from the Contributor Covenant. The full text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
