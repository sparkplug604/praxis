# Praxis v0.3.0

Praxis v0.3.0 adds the first Core intake layer for converting sources before they enter capture, chunking, search, SkillGraph memory, or agent workflows.

## Added

- `praxis intake` command group for source inspection, conversion, keyframe extraction, cache inspection, and intake health checks.
- Source detection and normalized evidence units for text, Markdown, HTML, PDF, CSV, JSON/JSONL, DOCX, PPTX, XLSX, images, audio, video, and directories.
- Parse-quality metadata, converter metadata, content hashes, artifact hashes, unit counts, and extraction warnings.
- Optional dependency extras for PDF, OCR, Office conversion, speech-to-text, scene detection, diarization, and visual embeddings.
- Transcript and OCR sidecar support for media files.
- Video keyframe, scene, OCR, diarization, word-timestamp, visual-embedding, and cache contracts for local media workflows.
- Intake metadata propagation into source captures, semantic chunks, and `praxis search --explain`.
- Release-hardening tests for intake conversion, metadata propagation, cache behavior, media sidecars, keyframes, and search warnings.

## Changed

- Core capture now uses the intake extraction path instead of separate ad hoc HTML/PDF/local-file readers.
- Intake documentation now lives under the Core module docs because Intake is a Core source-conversion capability.
- Package and CLI versions are aligned at `0.3.0`.

## Notes

Intake is designed to prevent damaged parser output from silently becoming durable memory. It does not make weak extraction trustworthy. Low parse quality, missing OCR, metadata-only media capture, or lossy Office extraction should be treated as warnings before using the resulting evidence in agent workflows.

The heavy media features are optional by design. The default install stays light, while local speech-to-text, OCR, scene detection, diarization, and visual embeddings can be installed only when needed.
