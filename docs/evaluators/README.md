# Praxis Evaluators

Use this folder for evaluation guides: short review paths that help a user decide whether a Praxis module fits a real workflow.

Run the fastest current evaluation:

```bash
praxis demo agency
```

## Folder Boundary

Evaluator docs are user-facing evaluation routes. They are not test suites, benchmark definitions, or CI checks.

Detailed module-specific evaluation guides should live with the module they evaluate. This folder stays as an index and compatibility area for people looking for evaluation material directly.
